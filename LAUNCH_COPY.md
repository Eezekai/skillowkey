> Show HN: I indexed 28,101 AI agent skills and removed 1,853 malicious/junk ones

Body:
I got tired of grazing endless GitHub repos looking for the right agent skill
(SKILL.md files for Claude Code, Gemini, etc.), so I built a searchable directory
and did the thing nobody else seems to: actually filtered the junk and malware.

- Search 28k agent skills with category/tag/star filters
- "Ask AI" natural-language search: "find me a skill to draft a terms of service"
- Every skill links to its real source repo (we host nothing)
- Real GitHub star counts (verified, not generated)
- A /verify page explaining exactly how the vetting works

Open API + Pro tier with USDC/USDT checkout if you want to build on the dataset.

Would love feedback on the vetting methodology and what the community would want
out of an agent-skill registry beyond search. This is the trust layer agent-skills
