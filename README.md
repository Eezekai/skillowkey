# Skillowkey

The verified library of agent skills. Searchable, sourced, license-aware.

- 5,444 skill entries indexed from 216 source repos
- Every entry SHA-256 hashed for integrity
- Pure static site — deploy free on Vercel / Netlify / GitHub Pages

## Deploy
Push this folder to a repo and connect to Vercel (free). Or:

    vercel --prod

## Files
- `index.html` — the full site + embedded skill data
- `vercel.json` — static config
- `robots.txt` — SEO
